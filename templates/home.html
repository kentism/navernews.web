KCSC News Monitoring Workspace

뉴스를 빠르게 찾고,
클리핑까지 한 번에 정리합니다

관련 검색어별 뉴스 검색, 실시간 알림, 카테고리별 클리핑 정리를 한 화면에서 처리하세요.

  • 관련 검색어를 여러 탭으로 나누어 동시에 모니터링할 수 있습니다.
  • +포함, -제외 조합으로 검색 결과를 더 정밀하게 조정할 수 있습니다.
  • 완성된 클리핑 최종본을 기준으로 학습 이력, 후보 선별, 백업 흐름을 이어갈 수 있습니다.
핵심 기능

업무 흐름에 맞춘 뉴스 클리핑 도구

검색, 후보 수집, 클리핑, 학습, 백업을 하나의 작업 흐름 안에서 다룰 수 있도록 구성했습니다.

검색 탭 기반 모니터링

주제별 검색 결과를 탭으로 열어두고, 필요한 검색어는 후보 수집 검색어로 이어서 관리합니다.

클리핑 최종본 학습

단순 클릭 기록이 아니라 실제로 완성한 클리핑 내용을 기준으로 기사 선별 패턴을 누적합니다.

백업과 복원

최종본 학습 직후 GitHub 백업을 실행하고, 새 배포 후에도 학습 이력을 복원할 수 있도록 구성했습니다.

사용 흐름

처음에는 이렇게 시작하면 됩니다

검색어를 입력하고, 필요한 기사를 클리핑한 뒤, 완성본을 학습시키고 후보 수집으로 확장하는 흐름입니다.

  1. 1

    검색 탭을 구성합니다

    주제별로 탭을 분리해 여러 검색 결과를 비교하고, 학습 탭에서 열린 검색어를 일괄 등록할 수 있습니다.

  2. 2

    중요 기사를 클리핑합니다

    기사 제목, 출처, 링크가 카테고리별 클리핑 모음에 추가됩니다.

  3. 3

    최종본을 학습시킵니다

    완성된 클리핑 내용이 후보 선별 기준으로 누적되고 GitHub 백업에도 반영됩니다.

  4. 4

    후보를 수집합니다

    학습 탭에서 검색어와 수집 기간을 정한 뒤 새 기사 후보를 확인하고 클리핑 여부를 판단합니다.

운영 참고

코드와 데이터는 별도로 관리됩니다

브라우저 임시 저장

작성 중인 클리핑 메모와 일부 화면 상태는 현재 브라우저에 저장됩니다.

서버 저장소

최종본 학습 이력, 후보 수집 검색어, 후보 데이터는 서버 DB에서 관리됩니다.

GitHub 백업

최종본 학습 직후 자동 백업이 실행됩니다. 새 배포 후 서버 DB가 비어 있으면 백업 복원을 우선 확인합니다.
