KCSC News Monitoring Workspace

뉴스를 빠르게 찾고,
클리핑까지 한 번에 정리합니다

관련 검색어별 뉴스 검색, 실시간 알림, 카테고리별 클리핑 정리를 한 화면에서 처리하세요.

  • 관련 검색어를 여러 탭으로 나누어 동시에 모니터링할 수 있습니다.
  • +포함, -제외 조합으로 검색 결과를 더 정밀하게 조정할 수 있습니다.
  • 필요한 기사만 클리핑 모음에 넣고 최종본을 학습 데이터로 저장할 수 있습니다.
핵심 기능

업무 흐름에 맞춘 뉴스 클리핑 도구

검색, 후보 수집, 클리핑, 학습, 백업을 하나의 작업 흐름 안에서 다룰 수 있도록 구성했습니다.

알림

실시간 알림

중요 검색어를 감시하고 새 기사 발생 여부를 클리핑 탭에서 바로 확인합니다.

검색

정밀 검색

포함어와 제외어를 조합해 불필요한 결과를 줄이고, 검색 결과를 여러 탭으로 비교합니다.

학습

최종본 기반 학습

단순 클릭이 아니라 완성된 클리핑 결과를 기준으로 후보 선별 패턴을 누적합니다.

사용 흐름

처음에는 이렇게 시작하면 됩니다

검색어를 입력하고, 필요한 기사를 클리핑한 뒤, 완성본을 학습시키는 흐름입니다.

  1. 1

    검색어를 입력합니다

    주제별로 탭을 분리해 여러 검색 결과를 동시에 비교합니다.

  2. 2

    중요 기사를 클리핑합니다

    기사 제목, 출처, 링크가 카테고리별 클리핑 모음에 추가됩니다.

  3. 3

    최종본을 학습시킵니다

    완성된 클리핑 내용이 후보 선별 기준으로 누적되고 GitHub 백업에도 반영됩니다.

운영 참고

코드와 데이터는 별도로 관리됩니다

브라우저 임시 저장

작성 중인 클리핑 메모와 일부 화면 상태는 현재 브라우저에 저장됩니다.

서버 저장소

최종본 학습 이력과 후보 데이터는 서버 DB에 저장됩니다. 현재 Koyeb 환경에서는 재배포 시 초기화될 수 있습니다.

GitHub 백업

최종본 학습 직후 자동 백업이 실행됩니다. 데이터가 사라져 보이면 백업 복원을 먼저 확인하세요.
