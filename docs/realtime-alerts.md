# 실시간 알림 기능

실시간 알림은 검색결과 탭의 알림 스위치를 켜면 해당 검색어를 감시 목록에 등록한다.

## 동작 흐름

- 사용자가 검색결과 탭에서 실시간 알림을 켜거나 끄면 브라우저의 감시 목록을 즉시 갱신한다.
- 토스트 메시지와 클리핑 탭의 실시간 알림 관리 목록은 로컬 상태를 기준으로 바로 갱신된다.
- 이후 서버에 `/api/watch`, `/api/unwatch`, `/api/sync-watch` 요청을 보내 현재 브라우저의 감시 목록을 동기화한다.
- 서버 동기화가 실패하면 사용자가 방금 바꾼 알림 상태를 이전 상태로 되돌리고 실패 토스트를 표시한다.

## 클리핑 탭 관리 창

- 클리핑 탭의 실시간 알림 관리 창은 현재 브라우저에 저장된 감시 목록을 표시한다.
- 검색결과 탭에서 알림을 켠 뒤 클리핑 탭을 나중에 열어도 같은 목록이 표시된다.
- 관리 창에서 개별 검색어를 끄거나 모든 알림을 초기화할 수 있다.
