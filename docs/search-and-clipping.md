# 검색과 클리핑

## 검색

일반 검색은 최신순 20건씩 조회한다. 스크롤과 `더 불러오기`로 다음 구간을 조회하며, 포함/제외 필터로 현재 페이지가 비어도 원본 페이지의 조회 위치를 유지한다. 검색 실패는 결과 0건으로 바꾸지 않고 오류와 재시도 경로를 표시한다. 새로고침 시 새 API 조회를 수행한다.

검색 탭의 시작일과 종료일은 한국 시간 기준이며 종료일 전체를 포함한다. 종료일을 비우면 한국 시간 오늘까지 조회한다. 기간 조회는 API가 제공하는 최신 최대 1,000건 안에서 시작일 경계까지 확인한다. `조회 완료`와 `조회 한도 도달`을 구분한다. 한도 도달 상태에서는 검색어를 구체화할 필요가 있으며, 날짜만 바꾸어도 API가 과거 기사를 더 제공하는 것은 아니다.

기간 조회는 제목/요약이나 과거 문서로 기사를 선별하지 않는다. 동일 원문 URL의 중복만 정리하며 서로 다른 URL의 관련 기사는 보존한다. 발행일을 판정할 수 없는 기사는 기간 결과에서 제외하고 건수를 표시한다.

## 선택과 편집

`전체 선택`은 해당 탭에 현재 표시된 기사에 적용된다. 일반 검색에서는 아직 불러오지 않은 기사가 포함되지 않는다. 기간 조회 후에는 조회된 전체 기사에 적용된다. 분류를 선택하고 `선택 기사 클리핑`을 누르면 한 번의 편집기 갱신으로 추가한다.

초안은 기존 `clippedTextContent` 저장 키를 사용한다. 기존 문서를 유지하고 동일 URL의 재추가를 막는다. 기사 날짜는 한국 시간으로 표기하며 `utm_*`만 제거한다.

일반 복사와 URL 제외 복사는 기존 공통 포맷터를 사용한다. `파일 저장`은 URL을 포함한 평문 TXT를 생성한다. 저장 상태는 브라우저 저장의 실제 성공 여부를 표시한다. 저장이 불가능해도 현재 화면의 문서는 파일로 보관할 수 있다. 외부 편집기 스크립트가 로드되지 않으면 일반 텍스트 입력란을 사용한다.

## 알림

알림 설정과 토스트, 클리핑 탭의 관리 영역을 유지한다. 알림 연결에도 로그인 인증을 적용한다. 새 기사 알림은 최신순 탭을 갱신할 수 있지만, 기간 조회 결과나 선택한 기사 목록을 자동으로 교체하지 않는다.
