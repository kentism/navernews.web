# 학습 탭 기능

학습 탭은 최종본 학습 이력, GitHub 백업 상태, 후보 수집 검색어, 후보 기사 목록을 한 화면에서 관리한다.

## 최종본 학습 이력

- 클리핑 탭에서 완성한 최종본을 학습하면 학습 이력에 저장된다.
- 학습 직후 GitHub 백업이 실행되며, 새 배포 이후 서버 DB가 비어 있을 때 복원 여부를 확인할 수 있다.
- 학습 이력은 후보 선별 기준이 누적되고 있는지 육안으로 확인하기 위한 운영 화면이다.
- 학습 이력을 삭제하면 해당 행이 먼저 삭제 중 상태로 전환되고, 서버 반영이 끝난 뒤 목록과 요약 정보가 새로고침된다.

## 후보 수집 검색어

- 후보 수집 검색어는 학습 탭에서 직접 추가하거나 제거할 수 있다.
- `현재 열린 검색결과 탭 키워드 일괄 추가` 버튼은 현재 브라우저에 열려 있는 검색결과 탭의 검색어를 읽어 후보 수집 검색어로 등록한다.
- 이미 등록된 검색어는 다시 추가하지 않는다.

## 후보 수집

- 수집 기간은 마지막 학습 시점 이후, 오늘 00시부터, 최근 24시간, 최근 3일 중에서 선택한다.
- 후보 수집은 등록된 후보 수집 검색어를 기준으로 네이버 뉴스 API를 조회한다.
- 수집된 후보는 점수와 판단 사유를 확인한 뒤 클리핑에 반영하거나 제외할 수 있다.
