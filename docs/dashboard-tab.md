# 대시보드 탭 기능

대시보드 탭은 기존 홈 탭을 대체하며, 후보 수집 기능을 기반으로 하루 단위 주요 보도 내용을 업무 분류별 보드로 정리한다.

## 수집 기준

- 기본 검색어는 `DASHBOARD_MAIN_KEYWORDS` 환경변수로 설정한다.
- 기본값은 `방송미디어통신심의위원회,방송미디어통신위원회`이다.
- 추가 보조 검색어가 필요하면 `DASHBOARD_EXTRA_KEYWORDS`에 쉼표로 구분해 설정한다.
- 대시보드 생성 시점 기준 한국시간 전날 10:00부터 현재 시각까지 작성된 기사를 대상으로 한다.
- 네이버 뉴스 API 조회와 후보 점수화는 후보 탭과 동일한 공용 수집 서비스를 사용한다.

## 분류와 중복 정리

- 수집된 후보는 기존 클리핑 분류와 같은 4개 섹션으로 배치한다.
  - `위원회 관련`
  - `방송·통신 관련`
  - `유관기관 관련`
  - `기타`
- 같은 URL, 같은 유사 그룹 키, 제목/본문 토큰 유사도가 높은 기사는 하나의 이슈로 묶는다.
- 대표 기사 1건만 카드로 표시하고 나머지는 `관련기사 N건`으로 접어 보여준다.
- 대표 기사는 후보 점수와 발행시각을 기준으로 선택한다.

## 검토와 최종본 저장

- 대시보드에 표시된 기사는 후보 탭의 `pending` 후보로 저장된다.
- 사용자는 대시보드에서 부적합한 기사를 최종본에서 제외할 수 있다.
- 사용자는 기사 분류를 직접 조정하고 최종본 미리보기 내용을 편집할 수 있다.
- `최종본 저장`을 누르면 현재 미리보기 내용이 기존 클리핑 최종본과 같은 학습 이력으로 저장된다.
- 대시보드 최종본 저장 직후 GitHub 백업이 자동으로 실행된다.
- 저장된 대시보드 최종본은 이후 후보 선별 점수화의 학습 근거로 반영된다.

## 환경변수

```env
DASHBOARD_MAIN_KEYWORDS=방송미디어통신심의위원회,방송미디어통신위원회
DASHBOARD_EXTRA_KEYWORDS=방심위,방통위
```

- `DASHBOARD_MAIN_KEYWORDS`: 대시보드 생성의 중심 검색어이다.
- `DASHBOARD_EXTRA_KEYWORDS`: 누락되는 이슈를 보완하기 위한 선택 검색어이다.
- 두 값은 서버 환경변수 또는 `.env`에 설정할 수 있다.
