# 클리핑 복사 양식

클리핑 탭은 같은 최종본 내용을 두 가지 방식으로 복사할 수 있다.

## 텍스트 복사

에디터에 저장된 원문을 그대로 복사한다.

```text
▷ 언론사명 : 기사 제목 (날짜)
<https://press.example.com/article/1>
```

이 양식은 기사 원문 URL을 포함하므로 최종본 학습, 백업, 기사 매칭 기준과 동일한 원본에 가깝다.

## 텍스트 복사(URL 제외)

에디터 원문은 변경하지 않고, 복사 시점에 URL만 단독으로 있는 줄을 제거한다.

```text
▷ 언론사명 : 기사 제목 (날짜)
```

이 기능은 외부 보고나 공유처럼 URL이 필요 없는 실무용 텍스트를 만들기 위한 출력 전용 기능이다. 학습 데이터, 서버 저장 내용, GitHub 백업 내용은 변경하지 않는다.
