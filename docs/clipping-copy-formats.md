# 클리핑 복사 양식

클리핑 탭은 같은 최종본 내용을 두 가지 방식으로 복사할 수 있다.

## 텍스트 복사

에디터에 저장된 Markdown 원문을 실무용 평문으로 변환해 복사한다. 강조 표시와 링크 문법은 제거하고 기사 URL 자체는 유지한다.

```text
▷ 언론사명 : 기사 제목 (날짜)
https://press.example.com/article/1
```

`<URL>`, `[URL](URL)`, `[표시문구](URL)`처럼 에디터가 생성할 수 있는 단독 링크는 모두 순수 URL 한 줄로 출력한다. `**제목**` 같은 Markdown 강조 문법도 평문으로 정리한다.

## 텍스트 복사(URL 제외)

일반 복사와 같은 평문 변환을 적용한 뒤, URL만 단독으로 있는 줄을 제거한다.

```text
▷ 언론사명 : 기사 제목 (날짜)
```

이 기능은 외부 보고나 공유처럼 URL이 필요 없는 실무용 텍스트를 만들기 위한 출력 전용 기능이다. 학습 데이터, 서버 저장 내용, GitHub 백업 내용은 변경하지 않는다.

## 에디터 버전

Toast UI Editor는 `3.2.2`로 고정한다. CDN의 `latest` 경로를 사용하지 않아 외부 라이브러리 갱신만으로 저장 및 복사 형식이 달라지는 상황을 방지한다.

복사 포맷 변환은 `static/js/clipping_copy_formatter.js`에 격리되어 있으며, 에디터 Markdown과 `localStorage`, 최종본 학습 데이터는 수정하지 않는다.
